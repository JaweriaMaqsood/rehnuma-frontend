1. What is the full form of CPU?

  • A) Central Program Unit
  • B) Central Processing Unit
  • C) Computer Personal Unit
  • D) Control Processing Utility
Show answer

Correct answer: B) Central Processing Unit
The CPU is the processor of the computer. It runs instructions.

  • C) Computer Personal Unit
  • D) Control Processing Utility
Jawab dekhein

Sahi jawab: B) Central Processing Unit
CPU computer ka processor hai jo instructions chalata hai.

3. What is the binary of decimal 5?

  • B) 100
  • C) 111

Show answer

Correct answer: D) 101
5 = 4 + 1, that is 1×2² + 0×2¹ + 1×2⁰ = 101.
