Computer Science Basics MCQs with Answers

Class 9, 10 aur FSc · Likhne wali: Javeria Maqsood, Rehnuma · Aakhri update: 18 November 2026

Computer ke ye 12 bunyadi MCQs Computer Science ke imtihan ki tayyari ke liye hain. Pehle khud jawab sochein, phir "Jawab dekhein" dabayein.

1. CPU ka poora naam kya hai?

  • A) Central Program Unit
  • B) Central Processing Unit
  • C) Computer Personal Unit
  • D) Control Processing Utility
Jawab dekhein

Sahi jawab: B) Central Processing Unit
CPU computer ka processor hai jo instructions chalata hai.

2. 1 byte me kitne bits hote hain?

  • A) 8
  • B) 4
  • C) 16
  • D) 10
Jawab dekhein

Sahi jawab: A) 8
1 byte = 8 bits.

3. Decimal number 5 ka binary kya hai?

  • A) 110
  • B) 100
  • C) 111
  • D) 101
Jawab dekhein

Sahi jawab: D) 101
5 = 4 + 1, yani 1×2² + 0×2¹ + 1×2⁰ = 101.

4. In me se kaun sa output device hai?

  • A) Keyboard
  • B) Mouse
  • C) Monitor
  • D) Scanner
Jawab dekhein

Sahi jawab: C) Monitor
Monitor maloomat dikhata hai, isliye output device hai.

5. RAM kis qism ki memory hai?

  • A) Non-volatile memory
  • B) Volatile memory (bijli band hone par data khatam)
  • C) Sirf parhne wali memory
  • D) Permanent storage
Jawab dekhein

Sahi jawab: B) Volatile memory (bijli band hone par data khatam)
RAM ka data bijli band hone par khatam ho jata hai.

6. HTML ka poora naam kya hai?

  • A) HyperText Markup Language
  • B) HyperText Making Language
  • C) High Text Machine Language
  • D) Home Tool Markup Language
Jawab dekhein

Sahi jawab: A) HyperText Markup Language
HTML web pages banane ki markup language hai.

7. 1 KB (kilobyte) barabar hai:

  • A) 1000 bytes
  • B) 100 bytes
  • C) 8 bytes
  • D) 1024 bytes
Jawab dekhein

Sahi jawab: D) 1024 bytes
Computing me 1 KB = 1024 bytes hota hai.

8. Computer ka "dimagh" kise kaha jata hai?

  • A) Monitor
  • B) Keyboard
  • C) CPU
  • D) Printer
Jawab dekhein

Sahi jawab: C) CPU
CPU saare processing kaam karta hai, isliye usay dimagh kehte hain.

9. In me se kaun sa operating system hai?

  • A) Microsoft Word
  • B) Windows
  • C) Google Chrome
  • D) Adobe Reader
Jawab dekhein

Sahi jawab: B) Windows
Windows ek operating system hai, baqi application software hain.

10. In me se kaun sa input device hai?

  • A) Mouse
  • B) Monitor
  • C) Speaker
  • D) Printer
Jawab dekhein

Sahi jawab: A) Mouse
Mouse computer ko input deta hai.

11. Binary number 1010 ka decimal kya hoga?

  • A) 12
  • B) 8
  • C) 5
  • D) 10
Jawab dekhein

Sahi jawab: D) 10
1010 = 1×8 + 0×4 + 1×2 + 0×1 = 10.

12. URL ka poora naam kya hai?

  • A) Universal Resource Link
  • B) Uniform Reference Locator
  • C) Uniform Resource Locator
  • D) United Resource Line
Jawab dekhein

Sahi jawab: C) Uniform Resource Locator
URL kisi web page ka pata (address) hota hai.
