Quadratic Formula aur Discriminant: step by step

Likhne wali: Javeria Maqsood, Rehnuma · Aakhri update: 2 November 2026

Quadratic equation ka standard rup ax² + bx + c = 0 hai (a ≠ 0). Is ko hal karne ka sab se pakka tareeqa quadratic formula hai.

Quadratic Formula

x = ( −b ± √(b² − 4ac) ) ÷ 2a

Ye formula "completing the square" se banta hai. Is mein a, b, c equation ke coefficients hain.

Discriminant (D)

D = b² − 4ac se pata chalta hai ke jawab kaise honge:

  • D > 0: do alag alag real roots.
  • D = 0: do barabar real roots.
  • D < 0: real roots nahi hote (complex roots).

Hal kiya hua sawal 1

x² − 5x + 6 = 0

a = 1, b = −5, c = 6. D = (−5)² − 4(1)(6) = 25 − 24 = 1.

x = (5 ± √1) ÷ 2 = (5 ± 1) ÷ 2, yani x = 3 ya x = 2.

Hal kiya hua sawal 2

2x² + 3x − 2 = 0

a = 2, b = 3, c = −2. D = 3² − 4(2)(−2) = 9 + 16 = 25.

x = (−3 ± 5) ÷ 4, yani x = 0.5 ya x = −2.

Tips

  • Pehle equation ko ax² + bx + c = 0 ki shakal mein likhein.
  • Negative b ke sath ehtiyat karein: −b ka matlab b ki ulti alamat.
  • Jawab ko equation mein rakh kar check kar lein.
