Hissa 1: MCQs (10)

Q1. Computer ka dimagh kise kehte hain?

  1. RAM
  2. CPU
  3. Monitor
  4. Mouse
Jawab dekhein

B) CPU

Q2. 1 byte mein kitne bits hote hain?

  1. 4
  2. 8
  3. 16
  4. 2
Jawab dekhein

B) 8

Q3. Decimal 5 ka binary kya hai?

  1. 110
  2. 101
  3. 111
  4. 100
Jawab dekhein

B) 101

Q4. Inmein se input device kaun sa hai?

  1. Monitor
  2. Printer
  3. Keyboard
  4. Speaker
Jawab dekhein

C) Keyboard

Q5. RAM kis qism ki memory hai?

  1. Volatile
  2. Permanent
  3. Optical
  4. Magnetic tape
Jawab dekhein

A) Volatile

Q6. Inmein se operating system kaun sa hai?

  1. Windows
  2. Excel
  3. Chrome
  4. Google
Jawab dekhein

A) Windows

Q7. URL ka poora naam kya hai?

  1. Uniform Resource Locator
  2. Universal Remote Link
  3. United Resource Line
  4. User Resource Locator
Jawab dekhein

A) Uniform Resource Locator

Q8. Inmein se output device kaun sa hai?

  1. Scanner
  2. Mouse
  3. Monitor
  4. Microphone
Jawab dekhein

C) Monitor

Q9. Data ki sab se chhoti unit kaun si hai?

  1. Byte
  2. Bit
  3. Kilobyte
  4. Nibble
Jawab dekhein

B) Bit

Q10. Kaun sa logic gate tab hi 1 deta hai jab dono inputs 1 hon?

  1. OR
  2. AND
  3. NOT
  4. XOR
Jawab dekhein

B) AND

Hissa 2: Mukhtasar sawal (3)

Sawal 1. RAM aur ROM mein farq likhein.

Namoona jawab dekhein

RAM temporary (volatile) memory hai jis ka data bijli band hone par khatam ho jata hai. ROM permanent memory hai jis ka data barqarar rehta hai.

Sawal 2. Binary 1010 ko decimal mein badlein.

Namoona jawab dekhein

1×8 + 0×4 + 1×2 + 0×1 = 10.

Sawal 3. Algorithm kya hota hai?

Namoona jawab dekhein

Kisi masle ko hal karne ke liye saaf aur tarteeb-war qadmon ki list ko algorithm kehte hain.
