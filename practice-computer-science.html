Part 2: Short questions (3)Hissa 2: Mukhtasar sawal (3)

Question 1. Write the difference between RAM and ROM.Sawal 1. RAM aur ROM mein farq likhein.

Show sample answerNamoona jawab dekhein

RAM is temporary (volatile) memory whose data is lost when the power goes off. ROM is permanent memory whose data stays.RAM temporary (volatile) memory hai jis ka data bijli band hone par khatam ho jata hai. ROM permanent memory hai jis ka data barqarar rehta hai.

Question 2. Convert binary 1010 to decimal.Sawal 2. Binary 1010 ko decimal mein badlein.

Show sample answerNamoona jawab dekhein

1×8 + 0×4 + 1×2 + 0×1 = 10.

Question 3. What is an algorithm?Sawal 3. Algorithm kya hota hai?

Show sample answerNamoona jawab dekhein

A clear, step-by-step list of steps to solve a problem is called an algorithm.Kisi masle ko hal karne ke liye saaf aur tarteeb-war qadmon ki list ko algorithm kehte hain.
