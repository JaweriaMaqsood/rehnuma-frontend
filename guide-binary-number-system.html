Decimal to BinaryDecimal se Binary

Divide the number by 2 again and again and write down the remainders. Then read the remainders from bottom to top.Number ko 2 se baar baar taqseem karein aur baqi (remainder) likhte jayein. Phir remainders ko neeche se oopar parhein.

Example: 13
13 ÷ 2 = 6 remainder 1
6 ÷ 2 = 3 remainder 0
3 ÷ 2 = 1 remainder 1
1 ÷ 2 = 0 remainder 1
From bottom to top: 1101.Misal: 13
13 ÷ 2 = 6 baqi 1
6 ÷ 2 = 3 baqi 0
3 ÷ 2 = 1 baqi 1
1 ÷ 2 = 0 baqi 1
Neeche se oopar: 1101.

Binary to DecimalBinary se Decimal

Multiply each digit by the power of 2 for its position and add them up.Har digit ko us ki jagah ki 2 ki power se zarb dein aur jama karein.

1101 = 1×8 + 1×4 + 0×2 + 1×1 = 13.

Binary additionBinary jama (addition)

0+0 = 0, 0+1 = 1, 1+1 = 10 (write 0, carry 1), 1+1+1 = 11.0+0 = 0, 0+1 = 1, 1+1 = 10 (0 likhein, 1 carry), 1+1+1 = 11.

101 + 011 = 1000 (that is, 5 + 3 = 8).101 + 011 = 1000 (yani 5 + 3 = 8).

Hexadecimal

In hex, A = 10, B = 11, C = 12, D = 13, E = 14, F = 15. Example: 255 = FF (hex) = 11111111 (binary).Hex mein A = 10, B = 11, C = 12, D = 13, E = 14, F = 15. Misal: 255 = FF (hex) = 11111111 (binary).
