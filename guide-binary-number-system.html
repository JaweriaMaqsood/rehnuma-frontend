Binary Number System: badalne ke asaan tareeqe

Likhne wali: Javeria Maqsood, Rehnuma · Aakhri update: 2 November 2026

Computer sirf 0 aur 1 samajhta hai, is liye saari maloomat binary (base 2) mein hoti hai.

Number systems ek nazar mein

NaamBaseDigits
Decimal100 se 9

Decimal se Binary

Number ko 2 se baar baar taqseem karein aur baqi (remainder) likhte jayein. Phir remainders ko neeche se oopar parhein.

Misal: 13
13 ÷ 2 = 6 baqi 1
6 ÷ 2 = 3 baqi 0
3 ÷ 2 = 1 baqi 1
1 ÷ 2 = 0 baqi 1
Neeche se oopar: 1101.

Binary se Decimal

Har digit ko us ki jagah ki 2 ki power se zarb dein aur jama karein.

1101 = 1×8 + 1×4 + 0×2 + 1×1 = 13.

Binary jama (addition)

0+0 = 0, 0+1 = 1, 1+1 = 10 (0 likhein, 1 carry), 1+1+1 = 11.

101 + 011 = 1000 (yani 5 + 3 = 8).

Hexadecimal

Hex mein A = 10, B = 11, C = 12, D = 13, E = 14, F = 15. Misal: 255 = FF (hex) = 11111111 (binary).
